The Repo
========

You probably shouldn't run this yourself because this only provides any privacy
if everyone uses the same Fedi-To. When you put your local instance into the
Remote Interaction Dialog, the remote fedi instance can see what your instance
is. Fedi-To works similarly to a fedi instance, but all the remote fedi instance
sees is Fedi-To itself. If you ran your own Fedi-To, the remote fedi instance
would be able to tell it's you. But talk to us about turning it into a co-op or
something, that would probably be a good idea at some point...
